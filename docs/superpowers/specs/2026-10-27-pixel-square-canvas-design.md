# 画布方块化展示与色号切换功能设计文档

- **创建日期**: 2026-10-27
- **文档状态**: Approved / Ready for Implementation Plan
- **涉及模块**: `src/components/BeadCanvas.tsx`, `src/components/BeadCanvas.scss`

---

## 1. 需求背景与目标

当前小呱拼豆的画布编辑区使用带孔圆环模拟实体拼豆珠子。为了提供更加清晰直观、像素风格鲜明且方便对照施工的视觉体验，提出以下两个核心改造需求：
1. **方块化展示**：彻底将圆孔拼豆样式替换为平面方块（像素方格）展示，网格边缘清晰，性能更加轻量丝滑。
2. **色号显隐开关**：在右下角悬浮操作栏（缩放工具条）中增加一个“色号”快捷切换按钮。开启时在每个方块上显示对应色号代码（如 `A10`、`M05`），关闭时隐藏色号文本。

---

## 2. 详细功能规范

### 2.1 画布方块渲染（Square Grid Rendering）
在 `BeadCanvas.tsx` 中替换原有的圆环/插孔逻辑，改用高性能的 2D 矩形渲染：
- **单元格填充**：
  - 坐标计算：`cellLeft = offsetX + x * scaledCell`, `cellTop = offsetY + y * scaledCell`。
  - 实心填充：使用颜色十六进制值 `cell.color.hex` 进行 `ctx.fillRect(cellLeft, cellTop, scaledCell, scaledCell)` 绘制。
- **网格分割线**：
  - 在每个方块周围保留 `0.5px ~ 1px` 极细微网格线，确保两个相邻的同色方块边界清晰可数。
  - 深色主题下使用浅透白线（`rgba(255, 255, 255, 0.08)`），浅色主题下使用浅透黑线（`rgba(0, 0, 0, 0.08)`）。
  - 保留每 5 格的主标尺线（深/浅色模式自适应加粗反差颜色），辅助用户迅速定位坐标。
- **空白格处理（Empty Cells）**：
  - 空白格统一填充底板占位块（浅灰或暗底），中心绘制微弱圆点或虚线边框，保证整齐统一。
- **寻豆高亮（Highlighting Mode）**：
  - 当通过底部色号条选中某个色号时：
    - 非目标颜色方块：透明度调整为 `0.18`（半透明暗化）。
    - 目标颜色方块：保持 `1.0` 不透明度，并在方块外部或内边缘叠加粗 `2px` 的亮黄色边框（`#FFE600`），产生明显的聚集高亮效果。

### 2.2 色号快捷切换与显示逻辑（Color Code Toggle & Overlay）
- **状态管理**：
  - 新增状态 `showColorCodes`（类型 `boolean`，默认为 `false`，支持记忆或持久化）。
- **右下角悬浮按钮（Zoom Bar 集成）**：
  - 位置：位于右下角悬浮缩放面板（`zoom-controls`）的“置中”按钮正上方。
  - 按钮样式：
    - 未激活状态：半透明背景，图标/文本为 `#` 或 `色号`。
    - 激活（开启）状态：背景高亮为品牌蓝色（`#3b82f6`），白色字体，视觉状态明确。
  - 交互行为：点击即切换 `showColorCodes` 的布尔值，并触发 `renderCanvas()` 重绘。
- **色号文字渲染算法**：
  - **展示门槛**：仅在 `showColorCodes === true` 且单元格显示尺寸 `scaledCell >= 14px` 时进行文字绘制；画布缩放至极小（小于 14px）时自动隐藏文字，防止文字粘连重叠导致画面模糊。
  - **动态字体大小**：
    - 字体大小根据格宽动态适配：`fontSize = Math.min(Math.max(8, Math.floor(scaledCell * 0.42)), 16)`。
    - 字体样式：`bold ${fontSize}px monospace`。
  - **对比度黑白自适应**：
    - 调用现有的 `getContrastTextColor(cell.color.hex)` 方法，深色背景方块绘制纯白文字（`#FFFFFF`），浅色背景方块绘制深黑文字（`#111111`），保证最佳可读性。
  - **文字居中对齐**：
    - `ctx.textAlign = 'center'`, `ctx.textBaseline = 'middle'`，绘制在 `(cellLeft + scaledCell / 2, cellTop + scaledCell / 2)`。

## 3. 非目标（Non-Goals）
- **图纸导出功能**：点击顶部导航“导出图纸”生成的高清施工图纸保持原有的标准拼豆图纸规范，本次改动不修改 `src/utils/exporter.ts`。

## 4. 测试与验证计划
1. **单元测试与现有测试回归**：
   - 运行 `npm run test`（vitest）确认量化、色彩匹配及核心工具模块全部测试通过。
   - 针对 `BeadCanvas` 渲染逻辑做断言验证。
2. **交互体验与视觉验证**：
   - 验证方块展示：在不同缩放比率下，方块无黑边错位、无亚像素闪烁，分割线规整。
   - 验证色号开关：开启后方块上正确显示对应色号，文字居中且黑白对比度清晰。
   - 验证缩放自适应：缩放至小图时文字自然隐去，放大时清晰展现。
   - 验证寻豆模式：选中色号时，目标方块黄色发光框正常，其余方块正确暗化。
