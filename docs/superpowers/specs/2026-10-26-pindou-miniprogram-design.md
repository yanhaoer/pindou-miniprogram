# 拼豆生成器（微信小程序）设计规范 (Design Spec)

## 1. 概述与目标 (Overview & Objectives)
拼豆（Perler Beads / Hama Beads / Fuse Beads）是一种风靡全球的像素手工艺术。
本项目旨在为广大拼豆手作爱好者提供一款运行于**微信小程序端**（同时支持浏览器 H5 即时预览调试）的高性能、现代美观的拼豆图纸生成与施工辅助工具。

### 核心目标
1. **开箱即用，极速转换**：支持微信拍照、相册选图以及精选内置样例，通过图像处理与像素重采样快速生成拼豆阵列。
2. **高保真色彩匹配**：基于人类色彩视觉模型的 **CIELAB $\Delta E_{2000}$** 工业级色差算法，精准匹配主流拼豆品牌色卡（Artkal 阿特卡、Perler、漫拼 Mard），杜绝普通 RGB 欧氏距离导致的暗部泛灰或偏色。
3. **拼豆材质与仿真渲染**：基于原生高性能 Canvas 2D 绘制逼真的立体圆珠质感（外圈渐变光影与中心定位微孔），支持多点手势丝滑平移与放大。
4. **实物施工辅助（智能寻豆）**：在用量清单中点击任意色号，底板对应所有该色号豆子高亮显示并附带醒目标记，其他豆子暗化，让用户在实物插板时轻松按色找位。
5. **高清图纸与用量统计导出**：生成包含外围行列刻度坐标（1~N）、拼豆实体网格、以及图例小票式色号与颗数统计的高清施工图，并一键保存到微信手机相册。

## 2. 系统技术架构 (Architecture)

### 2.1 技术选型
- **开发框架**：Uni-app (Vue 3 + Vite + TypeScript)
- **渲染核心**：Canvas 2D API（标准微信小程序 Canvas 2.0，兼顾 Web H5 Canvas 2D）
- **色彩计算**：纯前端离屏色差匹配引擎（预编译 Lab 色彩特征库与 $\Delta E_{2000}$ 快速查表缓存）
- **微信 API 集成**：`uni.chooseMedia`、`uni.canvasToTempFilePath`、`uni.saveImageToPhotosAlbum`

## 3. 功能模块详细设计 (Detailed Component Specs)

### 3.1 图像输入与样例选择模块
- **输入方式**：
  - 微信拍照或相册选图：调用 `uni.chooseMedia({ count: 1, mediaType: ['image'] })`。
  - 内置精选样例：预设 4~6 个典型高画质样例（例如宝可梦、像素小猫、像素马里奥等），免去用户初始无素材困扰。
- **参数控制**：
  - **底板规格**：预设 29×29（经典小板）、50×50（标准大方板）、52×52（拼豆大板），支持自定义宽高（10~100）。
  - **品牌色卡**：支持在 Artkal (阿特卡 A系列 2.6mm)、Perler、漫拼 Mard 之间自由切换。
  - **抖动开关**：可选无抖动（颜色色块分明，推荐动漫/ICON）或 Floyd-Steinberg 误差扩散（推荐写实照片）。

### 3.2 色彩量化与匹配算法模块
1. **色彩空间转换**：
   - 避免直接在 sRGB 下计算欧氏距离。将像素值转换至 CIELAB：
     ```
     sRGB -> Linear RGB (反向 Gamma 校正) -> CIE XYZ -> CIE L*a*b*
     ```
2. **CIELAB $\Delta E_{2000}$ 计算**：
   - 考虑明度加权 $S_L$、彩度加权 $S_C$、色相加权 $S_H$ 以及色相旋转项 $R_T$，计算两点在感知上的最小差异。
   - 色卡数据在初始化时完成 Lab 值预计算并缓存，像素比对时仅需与色卡内颜色计算距离。
3. **误差扩散处理（Floyd-Steinberg Dithering）**：
   - 当启用抖动时，将当前像素与匹配色彩之间的量化误差（Error）按权重扩散至邻近未处理像素：
     - 右方像素：$\times 7/16$
     - 左下方像素：$\times 3/16$
     - 下方像素：$\times 5/16$
     - 右下方像素：$\times 1/16$

### 3.3 Canvas 2D 交互渲染引擎
- **手势操作体系**：
  - `touchstart`、`touchmove`、`touchend` 处理：
    - 单指：画布平移（Pan）。
    - 双指：计算两指间距比率，以两指中心为焦点进行平滑缩放（Zoom，范围 0.5x ~ 10x）。
    - 点击模式切换：在“编辑模式”下，单指触控触发画笔涂色/吸管/油漆桶操作。
- **豆子材质渲染细节**：
  - **立体珠身**：绘制圆形并填充色号对应底色，外圈渲染轻微内阴影与高光反射渐变。
  - **中空微孔**：在中心绘制比例为外径 40% 的深色微孔，还原实物插板物理形态。
  - **标尺与网格辅助线**：每 5 格与每 10 格使用浅色半透明十字虚线，便于快速点数。
- **寻豆高亮（Find-a-Bead Mode）**：
  - 选中特定色号时：
    - 非目标豆子：覆盖层降低明度（透明度 20%~30%）。
    - 目标豆子：100% 原始色彩，外圈绘制醒目的荧光标记（白色内线 + 亮黄发光外圈），并在放大时可清晰看到该单元格标注。

### 3.4 手动微调工具箱
- **画笔工具 (Pencil)**：点击或划过网格，将对应单元格修改为当前选定色号。
- **油漆桶工具 (Bucket Fill)**：基于 BFS（广度优先搜索）对同色连通区域进行批量替换。
- **吸管工具 (Eyedropper)**：点击画布上任一豆子，自动将当前激活色号切换为该豆子色号并在清单中定位。
- **橡皮擦 (Eraser)**：将单元格重置为空（透明插针状态）。
- **历史记录 (Undo/Redo)**：支持最近 20 步操作的撤销与重做。

### 3.5 施工图纸与统计清单导出
- **离屏超清渲染（Export Canvas）**：
  - 自动根据板子尺寸（如 50×50）计算最佳画布分辨率（输出图片像素宽度约 1600px~2400px，保证打印清晰）。
  - **外围标尺**：图纸四周标有 1, 2, 3 ... 50 的数字标尺。
  - **图例清单汇总表**：在图纸下方排版各色号的色块样本、品牌编号（如 A01、A14）、颜色名称以及所需数量（例如 `A01: 350颗`）。
- **微信文件保存**：
  - 调用 `uni.canvasToTempFilePath` 生成 PNG。
  - 调用 `uni.saveImageToPhotosAlbum` 保存至相册。
  - 完善的授权失败容错处理（若用户未开启相册权限，弹出对话框引导前往小程序设置页面开启）。

## 5. 质量保证与测试验证标准
1. **色彩还原验证**：验证典型色彩（黑、白、红、黄、肤色、渐变蓝）在各个品牌色卡中均能匹配至视觉最自然的色号。
2. **手势与性能验证**：在 50×50 底板规格下，双指缩放及单指拖动平稳保持 60fps，无卡顿和抖动。
3. **寻豆高亮正确性**：点击色号，底板精确高亮且高亮计数与用量清单总数严格一致。
4. **导出完整性**：生成的图片在手机相册中清晰可见行列坐标与色号清单，无错位或文字重叠。
